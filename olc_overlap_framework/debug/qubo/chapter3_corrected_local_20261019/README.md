# 第三章：修正后的本地复测

本次测试使用历史 WSL 虚拟环境，复用 Actions 39165072682 的输入图。参数仅在 seed 900011、900013 的预检中选择，正式批次使用固定的 40–45 六组 seed。每组为 100 个独立随机初态的 read，每个 read 用一个不同的、可复现的内部采样 seed；1000 sweeps，32 切片，beta=5、gamma=1，不修复输出。

## 上一轮异常的原因

1. OpenJij 的批量采样循环对每个 read 重新调用同一个 seed。在同时指定相同初态时，本轮原始三个预检工件各有 100 个完全相同的输出，不能解释为 100 次独立探索。修正后逐个 read 调用 num_reads=1，并保存其独立初态和内部 seed。
2. 历史成功测试含有 overlap 目标项；上一轮改成纯结构约束，改变了实际测试的哈密顿量。
3. 同时把约束尺度降到 1，仍固定 beta=5、gamma=1，也改变了采样的有效能量尺度。

因此，上一轮数据保留用于追溯，不作为这次正式性能比较的数据。这里没有把“程序执行成功”算作“求解成功”。

## 正式比较

主比较对位置变量加权扩展、a、b 使用相同目标项：负的归一化 overlap 长度总和，目标权重统一为 40。

| 模型 | 约束系数 | 目标权重 |
|---|---|---|
| 位置变量加权扩展 | 每个 read 一次=140，每位置一次=140，缺失边=110 | 40 |
| a | 边数=40，次数冲突=60 | 40 |
| b | read 次数和起终点选择=40 | 40 |

N=8、12、16、20 比较三种模型；N=35、70、100 比较 a、b。共 108 次正式试验。加权位置变量模型是原式的扩展，不能标成未修改的原式。

另有 24 次原始位置变量式对照：三个约束系数均为 40，overlap 目标为 0，N=8、12、16、20，仍使用六组 seed 和相同采样预算。长度、GC、MI 补助项均未加入。

## 基底与合法性核对

每个返回状态都根据原始比特核对 read/位置分配、选择边数、入出度、起终点数量，以及是否完整遍历全图。记录约束能量和目标能量。未把非法赋值投影为排列，也未删除边或拼接路径。

纯约束原式的下界为 0；已知合法路径达到该下界。加权主比较的下界为 -40(N-1)，且本组数据的参照路径达到该值。下界成立的充分条件已写入脚本，逐组记录并检查：

- a：若选择边数 k=N-1+d，每条边奖励不超过 R，则 A_count*d²-R*d>=0（整数 d，A_count>=R）；次数惩罚非负。
- b：read 次数与起终点选择残差总和至少为 2|k-(N-1)|，因此 2*A_degree>=R 足够。
- 位置变量型：令每列选择数 c_j=1+b_j，整数 b_j 有 sum(c_j*c_(j+1))<=N-1+3*sum(b_j²)。位置惩罚>=3R 足够，其余惩罚非负。

此外，在三顶点图上穷举核对了三种加权模型的展开式、独立计算的约束/目标能量、下界及唯一基态。
