## 观察

1. N ≤ 48 时 QbSolv 几乎总能得到最优路径，耗时约 1–3 秒；SQA 在同样规模下有效率和最优率都明显更低，耗时却多出几十倍。
2. 从 N = 72 起 QbSolv 一条有效路径也得不到；SQA 仍偶尔得到有效路径，N = 96 时有 1 次命中最优。
   但每个设置只有 6 次试行，SQA 的结果并不随 N 单调变化（N = 96 好于 36–72），差异可能主要来自随机性和窗口结构，不宜过度解读。
3. QbSolv 返回的最低能量样本始终远高于参考路径的能量（例如 N = 12 时为 146.2 对 2.2，N = 48 时为 2,605.9 对 13.9）。
   即使从 x_e 解码出的路径是最优的，顺序 bit 和 borrow bit 也不一致：
   N = 12 的最低能量样本有 1 处 selected_order_violation，相当于一份罚项 144。
   这说明「有效路径」的判定只看 x_e，并不代表 QUBO 基态已经找到。
4. SQA 的 summary 没有记录最低能量，因此第 3 点无法在 SQA 上做同样的比较。
5. 末尾窗口只有 2–4 条 Hamilton 路径，比完整 complex144 的 192 条简单得多。
   仓库里另一个小数据是 phiX174 cycle12（12 reads 的单环），结构更简单，没有用在这里。

## 结论

- 小规模时经典 tabu（QbSolv）明显强于 SQA，所以「SQA 比经典方法差很多」在 N ≤ 48 时成立。
- 规模变大后两者都失效：QbSolv 在 N ≥ 72 时突然失败，SQA 则以低概率继续得到解。
- 无论哪个求解器都没有到达 QUBO 基态，所以瓶颈可能在顺序变量部分的能量景观，而不只在求解器本身。
