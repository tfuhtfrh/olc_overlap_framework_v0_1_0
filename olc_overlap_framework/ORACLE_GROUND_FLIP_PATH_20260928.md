# Oracle ground-state flip path — CHM13 complex144 — 2026-09-28

This is a geometry diagnostic, not a production solver.  The certified optimum
is used as an oracle target to expose the exact symmetric-difference structure.

## Stuck state versus optimum

Stuck checkpoint:
- 143 selected edges
- degree conflicts 0
- one source and one sink
- one directed cycle
- not a Hamilton path

Certified optimum:
- Hamilton path score 1,343,093
- same source as the stuck state
- different sink

The two edge sets differ in exactly 16 bits:
- 8 selected edges must be removed
- 8 unselected edges must be added

In the tail/head bipartite representation, this symmetric difference decomposes
into exactly four disjoint alternating components:

1. one open alternating path, k=1
2. one closed alternating cycle, k=2 (R2)
3. one closed alternating cycle, k=2 (R2)
4. one closed alternating cycle, k=3 (R3)

Thus the exact target difference is structurally very small despite spanning
16 edge bits.

## Four-component route

A valid oracle route is

    open k1 -> R2 -> R2 -> R3

with metrics

- start: cycle=1, invalid
- after open k1: Hamilton path, score 1,299,598
- after first R2: cycle=1, invalid
- after second R2: Hamilton path, score 1,316,426
- after R3: Hamilton path, score 1,343,093 (certified optimum)

Another useful ordering is

    open k1 -> R3 -> R2 -> R2

with

- after open k1: Hamilton path, score 1,299,598
- after R3: Hamilton path, score 1,326,265
- after first R2: cycle=1, invalid
- after second R2: Hamilton path, score 1,343,093

All 24 component orders were checked.  No order keeps every post-endpoint-repair
intermediate state Hamilton-feasible when the four components are applied
individually.  At least one temporary cycle state is required under this
restricted component basis.

## Feasibility-preserving macro route

The two R2 components can instead be applied simultaneously as one disconnected
compound proposal.  Then the macro-boundary route is

    open k1
      -> R3
      -> (R2 + R2) compound

and every state after the first endpoint repair is a Hamilton path:

- 1,299,598
- 1,326,265
- 1,343,093

The two objective improvements are +26,667 and +16,828 in path score.

This compound move is not a single connected alternating cycle; it is the
simultaneous application of two disjoint R2 cycles.  It is therefore a separate
proposal family if used by a sampler.

## Important projected-rank caveat

With the *stale rank certificate from the stuck checkpoint held fixed*, the
certified optimum has higher projected-BQM energy:

- stuck energy: 70.2672860461
- optimum energy under stale rank: 83.3092132690
- difference: +13.0419272229

The four oracle components are all uphill under that stale certificate.

This does not contradict the weighted optimum.  The order penalty is an
auxiliary certificate term.  Once a valid path is obtained and its rank is
reprojected, the path itself has zero backward edges under its own rank.  At
fixed cardinality and zero degree conflicts, improving the overlap score lowers
the intrinsic weight cost.

Therefore the cleanest algorithmic interpretation is hybrid:

1. use an open alternating trail to change endpoint fiber;
2. reproject rank after entering a valid path;
3. use closed R2/R3 or small compound reconnects for weight refinement;
4. allow either a short temporary-cycle excursion or a compound proposal when
   two individually-invalid reconnects cancel each other's topology defect.

## Research implication

The exact ground-state route does not require very large blind k-exchange.
The target difference is generated by the small structured basis

    open k1 + R2 + R2 + R3.

The remaining production problem is proposal discovery: identify such open
endpoint-transfer trails and complementary closed reconnects without access to
the optimum.
